Política de Privacidade — mailtriage

Última atualização: 19 de novembro de 2026

O que é este software

O mailtriage é um programa de código aberto que organiza uma caixa de email: ele lê as mensagens que chegam, classifica cada uma segundo regras definidas por quem o usa, e então aplica rótulos, move mensagens entre pastas ou as descarta conforme essas regras.

Ele é auto-hospedado. Cada pessoa executa a sua própria instância, no seu próprio computador ou servidor. Não existe serviço central, não existe conta a criar, e não há operador que receba os dados de ninguém.

Quais dados são acessados

Apenas a caixa de email que a própria pessoa autorizar, e apenas enquanto a autorização estiver válida. O programa lê o remetente, o assunto e um trecho do corpo de cada mensagem, porque precisa deles para classificar.

Para onde esses dados vão

Para lugar nenhum além da máquina de quem executa o programa.

  • Não há servidor do desenvolvedor. Nada é enviado para fora.
  • Não há analytics, telemetria, rastreamento ou coleta de uso.
  • Não há compartilhamento com terceiros, porque não há terceiros.
  • Nenhum conteúdo de email é usado para treinar modelo algum.

O programa guarda localmente um histórico das decisões que tomou — remetente, assunto e categoria atribuída — num banco de dados no próprio disco. Esse histórico serve para não reprocessar a mesma mensagem e para gerar relatórios. O corpo das mensagens não é armazenado.

Permissões solicitadas

O programa pede o escopo gmail.modify, que é o mínimo necessário para aplicar rótulos e mover mensagens entre pastas. Ele não solicita acesso a contatos, agenda, arquivos ou qualquer outro serviço.

Esse escopo tecnicamente também permitiria enviar email. O programa não envia: há um bloqueio no seu código que recusa qualquer chamada a endpoints de envio antes que a requisição saia da máquina. Isso é verificável no código-fonte e coberto por testes automatizados.

Credenciais

O programa nunca vê nem armazena senhas. A autorização usa OAuth 2.0, e o token resultante fica em arquivo local com permissão restrita ao usuário do sistema. Nenhuma credencial é transmitida para fora da máquina.

Como revogar o acesso

A qualquer momento, em myaccount.google.com/permissions, removendo a autorização concedida. O acesso cessa imediatamente. Apagar os arquivos locais do programa remove o histórico guardado.

Retenção

Como todos os dados ficam na máquina de quem executa o programa, a retenção é inteiramente controlada por essa pessoa. Não há cópia em nenhum outro lugar para ser retida ou apagada.

Alterações

Mudanças nesta política aparecem nesta mesma página, com a data de atualização no topo.

Software de uso pessoal, distribuído como código aberto. Dúvidas sobre o funcionamento podem ser respondidas lendo o código-fonte, que é a descrição mais fiel do que o programa faz.
