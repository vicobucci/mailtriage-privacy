# mailtriage — política de privacidade

Esta página existe para satisfazer o requisito de URL pública de política de
privacidade na tela de consentimento OAuth do Google.

O software em si é um agente de triagem de email auto-hospedado: ele roda na
máquina de quem o usa, organiza a própria caixa dessa pessoa, e não envia
dados para servidor nenhum.

Publicado em: <https://vicobucci.github.io/mailtriage-privacy/>
